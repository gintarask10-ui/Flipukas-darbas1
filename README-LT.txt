FLIPUKS ATELIER — GitHub Pages

1. Išarchyvuokite ZIP.
2. GitHub repozitorijoje pasirinkite Add file → Upload files.
3. Įkelkite index.html ir .nojekyll tiesiai į pagrindinį repozitorijos aplanką.
4. Paspauskite Commit changes.
5. Eikite į Settings → Pages.
6. Pasirinkite Deploy from a branch → main → /(root) → Save.
7. Palaukite kelias minutes.

Pastaba: šiame HTML faile nuotraukos vis dar įkeliamos iš pradinės svetainės, todėl joms reikalingas internetas.
